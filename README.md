A clean, modern, and responsive personal portfolio website built with pure HTML5 and CSS3 (inspired by the classic Leon agency template design). 

This project serves as a showcase of my technical skills, university programming coursework, design interests, and learning journey as an IT Engineering student.

## 📌 Features

- **Responsive Header & Navigation:** Clean menu with intuitive anchor links to all sections.
- **Hero / Landing Section:** Introduction presenting my profile and academic focus.
- **Key Highlights (Core Values):** Showcases Creative Thinking, Continuous Learning, and Technology passion.
- **Skills Section:** Displays current focus areas including:
  - UI & UX Design
  - HTML & CSS Web Development
  - C# & Object-Oriented Programming (OOP)
  - Git & GitHub Version Control
- **Projects Showcase:** Highlights hands-on projects (Web Development, UI/UX, and C# University Projects).
- **About Me:** Overview of my academic background in Information Technology.
- **Contact & Social Connect:** Direct Gmail compose integration and quick links to Instagram, GitHub, and LinkedIn.

---

## 🛠️ Built With

- **HTML5:** Semantic document structure.
- **CSS3:** Custom styling, Flexbox, CSS Grid, media queries for responsiveness, and normalize.css reset.
- **Font Awesome:** Scalable vector icons.
- **Google Fonts:** Clean typography using *Work Sans*.

## 💻 How to Run Locally

1. **Clone the repository:**
   git clone https://github.com/amanaldaher/Personal_Portfolio1.git
2. **Navigate to the project directory:**
   cd Personal_Portfolio1
3. **Open the project:**
   - Double-click `index.html` to open it in your browser.
   - Or open the folder in **VS Code** and run it using the **Live Server** extension.
